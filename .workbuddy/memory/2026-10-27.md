## 新增第 7 维：市场拥挤度（params v2.2，已完成）

**来源**：量化投资邢不行《如何判断抱团行情？》(YouTube `Fq4Le_j2E4g`)。指标 = 成交额排名前 5% 个股成交额 ÷ 全市场成交额。

**口径坑（重要）**：必须是**月度累计（MTD）**，不是单日。
- 2026-06 实算 48.81% vs 视频 48.76%（误差 0.05pp）
- 2021-01 实算 48.54% vs 视频 49.51%（误差 0.97pp）
- 单日口径 2026-06-30 得 52.26%，偏高 3.5pp，套 45% 阈值会天天误报 → R-013 明确禁用

**设计决策**：不进六维方向总分，作**覆盖层**。理由：45%+ 是双向信号（2008-09 熊底 48.99% 也会触发），塞进方向轴会污染 regime。覆盖规则见 params_v2.2.crowding.overlay_rules（7 条）。

**改动清单（7 处）**：
1. `scripts/compute_crowding.py` 新增（17 秒全量 / 3 秒增量，纯标准库）
2. `knowledge/params_v2.2.json` 新增 crowding 段，params_current → v2.2
3. 市场分析师 prompt：第 7 维章节 + 步骤 1.5 取数 + 步骤 3.5 覆盖层；regime.json 加 crowding 对象 + position_cap_pct
4. `send_report_mail.py`：邮件加拥挤度区块（数值 + 水位条 + 45/50 红线 + 四宫格）
